# Overview

## Executive Summary
Samvaad represents a platform which allows to have a dialogue, conversation, discussion or debate.The purpose of this product is give a free, open source tool to allow setting up of video conferencing. Samvaad intents to offer a product that can be used by anyone to deploy their own video conferencing solution. The product being open source will rely on the community to contribute and extend its capabilities.

# Problem Statement

## Lack of fully open source video conferencing applications
Popular video conferencing tools today are not open source. Their core source code is owned by their respective owners. 

## Creating a fresh WebRTC based product
We will create a fresh WebRTC based application from the ground up.s


# Value Proposition
Green field project which will give experience in learning to develop a video conferencing application. It will allow developer community to offer video conferencing solutions that can be freely enhanced or repurposed.

# Risks
1. No Program management or seed funding
2. Experimental development
3. Can end up as developing a redundant product 

# Success Criteria
1. Developing a finished, working MVP product
2. Ease of use
3. Ease of setup for anyone to use it and host a video conferencing solution

# Requirements and Scope
## MVP

1.  Supports browser based peer to peer video calling
    * Peer to peer video calling
    * Support for screen sharing
    * Support for chat
2.  Supports group video calls
    * Supports group video calls for N users
    * Support for breakout rooms
    * Adaptive to network conditions
